# Security and private data

Never add API keys, tokens, personal paths or private reference images to a workflow,
screenshot, issue or commit. Configure provider credentials through the node's
supported configuration; do not embed them in shared JSON.

Manual image generation does not request an Auto Prompter response. Clicking
Generate Prompt sends configured prompt/reference content to xAI and may incur
provider charges.

For a security concern, contact MATRIX LAB through the private channel used to
receive this package. Do not attach credentials. Include the release version and
a redacted description. Use the private repository's issues for ordinary support.
