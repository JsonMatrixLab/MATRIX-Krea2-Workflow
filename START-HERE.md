# MATRIX Krea 2 V1 — Start here

1. Read [INSTALL.md](INSTALL.md) and install the required node packs.
2. Download the files listed in [MODELS.md](MODELS.md) into their ComfyUI model folders.
3. Open ComfyUI Classic and drag **MATRIX-Krea2-V1.json** into the canvas.
4. Choose 2K or 4K, edit the manual prompt and keep the prompt switch OFF / Manual.
5. Run when ready and download the saved output if using a remote server.

The [illustrated guide](README.md) explains each stage. The JSON under `API/` is for automation, not the canvas. Models are separate downloads. Optional LoRAs start OFF.

Custom nodes: [MATRIX-LAB-Nodes](https://github.com/JsonMatrixLab/MATRIX-LAB-Nodes) and [rgthree-comfy](https://github.com/rgthree/rgthree-comfy).
